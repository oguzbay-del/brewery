# SegmentedControl

2–5 seçenekten biri; aynı ekranda görünümü veya türü değiştirir.

- Ray `fill`, `radius-sm`; seçili parça `card`, `shadow-seg`, 600 ağırlık.
- Seçenek adları kısa, tek kelime ("Şişe", "Kutu", "Keg", "Cask"). Beşten fazla seçenek için liste veya açılır seçici kullan.
- Gezinme için değil (o iş sekme çubuğunun); yalnız aynı içeriğin görünümü veya bir alanın değeri için.

Kullanan sağlar: seçenekler, seçili değer, değişince çağrılan işlev.
