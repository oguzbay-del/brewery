# BrewReturnBar

Demleme sürerken kullanıcı başka ekrana geçtiğinde sekme çubuğunun hemen üstünde duran şerit; dokununca demleme gününün aktif adımına döner.

- `tint-fill` zemin, `tint-ink` yazı, `radius-lg`; sağda kalan süre (SF Pro Rounded, eş genişlikli rakam).
- Yalnız süren bir demleme varken görünür; iPad'de kenar çubuğunun üstünde.
- Telefon ve Haritalar'ın süren arama/yol tarifi şeridi gibi çalışır.
- Metin: "Demlemeye dön · <adım> <sıra>/<toplam>".

Kullanan sağlar: aktif adımın adı ve sırası, kalan süre, dokunma eylemi.
